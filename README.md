# TDC E-Commerce

Platform e-commerce untuk membantu UKM TDC dalam menjual dan mengelola produk.

## Tentang Project

TDC E-Commerce adalah aplikasi web untuk menjual produk TDC secara online.
Aplikasi ini memiliki fitur untuk melihat produk, memilih variant, mengelola keranjang, checkout, membuat order, dan mengelola pesanan.

## Masalah

TDC membutuhkan sebuah sistem yang dapat membantu mengelola produk dan pesanan dalam satu tempat.

Project ini dibuat untuk membuat proses penjualan dan pengelolaan produk menjadi lebih mudah dan teratur.

## Fitur

### Customer
- Melihat daftar produk
- Melihat detail produk
- Memilih product variant
- Menambahkan produk ke cart
- Melakukan checkout
- Membuat order

### Admin
- Melihat dashboard
- Mengelola product variant dan stock
- Melihat daftar order
- Mengubah status order

## Tech Stack

- Frontend: Next.js, React, TypeScript
- Backend: Golang, Gin, GORM
- Database: PostgreSQL
- API Documentation: Swagger
- API Testing: Bruno
